
Simple Stock App for iPhone

Features:
- Product Code Input
- Unit Price
- Quantity
- Auto Total
- Full Total Calculation

How to Run:
1. Open Xcode on Mac
2. Create new iOS App
3. Replace ContentView.swift with the provided code
4. Run on iPhone or Simulator

You can later add:
- Barcode Scanner
- Camera Scan
- iCloud Backup
- PDF Export
